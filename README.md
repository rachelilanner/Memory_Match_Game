# About Memory Match Game
This project is a fun and interactive memory game designed to test and improve the player’s memory and teach them general cyber-security terms. In this memory game all cards start face down. Each card shows an index number and a question mark. The player chooses 2 card indices to try and find matching pairs. While guessing, the cyber terms on the 'cards' stay hidden, untill the player finds a matc. Then, matching terms are revealed and stay visible for the remainder of the game. The goal is to find all matching pairs, all the while using visual feedback for correct and incorrect matches, and comments on correct or incorrect attempts at a match!
